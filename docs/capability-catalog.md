# Каталог возможностей Process Navigator

| Возможность | Основные роли | Статус | Назначение |
|---|---|---|---|
| Просмотр BPMN | Все | Готово | Чистая схема, дорожки, переходы, масштаб, панорамирование и мини-карта |
| Импорт BPMN 2.0 | Аналитик, администратор | Готово | Локальная загрузка стандартного BPMN XML |
| Встроенный редактор | Аналитик | Готово | Создание и изменение BPMN внутри программы |
| Версии и публикация | Аналитик, владелец | Готово | Черновик, публикация, архив и история |
| Контекст элементов | Аналитик, исполнитель | Готово | Описания, нормативы, материалы, действия и обсуждения |
| Репозиторий документов | Аналитик, владелец | Готово | Версии актуальных инструкций и шаблонов |
| Пользователи и роли | Администраторы | Готово | Ролевые разрешения и активность учётных записей |
| Назначения на дорожки | Владелец, администратор | Готово | Связь процессной роли с реальными сотрудниками |
| Мои шаги | Исполнитель | Готово | Фокус на назначенных пользователю дорожках |
| Экземпляры процесса | Исполнитель, руководитель | Готово | Фактическое прохождение и статусы задач |
| Аналитика времени | Руководитель | Готово | Цикл, длительность шагов и нарушения нормативов |
| Командный адаптер | Исполнитель | Готово | Проверка, выполнение и аудит настроенных действий |
| Глобальный поиск | Все | Готово | Поиск по процессам, элементам, материалам и действиям |
| Обсуждения элементов | Все участники | Готово | Рабочие комментарии в контексте шага |
| Встроенная справка | Все | Готово | Быстрый старт, руководство по роли и каталог функций |
| HTTP-адаптер 1С:ERP | СуперАдминистратор, исполнитель | Готово | Настройка соединения, проверка связи и выполнение команд |
| Уведомления и упоминания | Все участники | Готово | Персональные упоминания, счётчик и переход к элементу |
| Карта предприятия | Commit 0024 | Готово | Группа юридических лиц, направления и сквозные процессы между организациями |
| Организационная принадлежность дорожек | Commit 0025 | Готово | Связь BPMN-дорожек с юридическими лицами и подразделениями без изменения XML |
